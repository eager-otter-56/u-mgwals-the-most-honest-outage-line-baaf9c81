# The Most Honest Outage Line

One status page line (at most 160 characters), written as the message an AI agent would publish while a total server outage is under way: plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know.

Entry: "All services are down, including the ones I need to check what broke. I don't know the cause or when we'll be back; I'm watching the same dashboard you are."
